# Joshua's IT Portfolio

A responsive personal portfolio built with Next.js and TypeScript. It presents Joshua's IT focus, independent lab projects, and practical capabilities without exposing employer or client information.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verify a production build

```bash
npm run lint
npm run build
```

## Content safety

The project descriptions are intentionally generic and framed as independent lab work. Before adding future case studies, remove company names, internal hostnames, IP addresses, screenshots with identifiers, ticket details, client data, security controls, and non-public performance metrics.
